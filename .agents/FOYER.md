# Page /family (foyer)

Cette page permet d'ajouter des membres de la famille et configurer les dépenses et revenus récurrents du foyer.

Il y a plusieurs catégories :
- Budget
- Cœur
- Crédit
- Loisir
- Et une catégorie pro. par membre de la famille

Il est possible, pour chaque dépense/revenu, de configurer :
- L'intitulé
- Une description
- La catégorie
- Le mouvement (positif ou négatif)
- Un bouton qui ouvre une modal pour cocher la case "estimation" ou non
> Une estimation permet de donner une valeur minimale et une valeur maximale pour les déoenses/revenus variables
- La récurrence (en mois)

La vue s'affiche sous forme de tableau. L'ajout de membre via un bouton + modale.
