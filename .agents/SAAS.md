# Family-Fi SaaS

## Sommaire

Il s'agit d'un SaaS de gestion de finances de couple/famille.

L'outil tourne sous :
- Front : React.js + Material UI (MUI) + react-i18next (i18n anglais par défaut + français + japonais)
- Back : Hono - Node.js preset + Better Auth

Le SaaS est mobile-first : supporte mobile, tablette et desktop.

## Charte graphique

La charte graphique est configurée proprement avec MaterialUI. Pas de hard-code composant par composant.
